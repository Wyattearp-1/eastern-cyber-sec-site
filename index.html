The CIA Triad

🛡️

What is the CIA Triad?

Three core goals of information security that guide all security decisions:

ConfidentialityOnly authorized access (encryption, access controls)
IntegrityData stays accurate & unaltered (hashing, checksums)
AvailabilitySystems accessible when needed (backups, redundancy)

Threats & Malware

🦠

Common Malware Types

Virus — Attaches to files, needs user action to spread
Worm — Self-replicates across networks without a host
Trojan — Disguised as legitimate software
Ransomware — Encrypts data, demands payment
Spyware/Keylogger — Secretly records activity & credentials

Types of Encryption

SymmetricOne shared key (fast, key distribution is hard)
AsymmetricPublic/Private key pair (slower, solves key distribution)

Hashing — One-way function for integrity verification (NOT reversible)

Strong Password Requirements

A good password should have:
✓ At least 12 characters
✓ Mix of uppercase & lowercase letters
✓ Numbers included
✓ Special symbols (!@#$%^&*)
✓ No common words or personal info
